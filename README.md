# Weather-App

A responsive weather dashboard built with React and Vite, powered by the Open-Meteo API.

Features:
- Current temperature and feels-like temperature
- Humidity and wind speed
- Weather condition icons and summaries
- City search
- 5-day forecast cards

## Run locally

```bash
npm install
npm run dev
```

## Tech stack
- React
- Vite
- Bootstrap
- Bootstrap Icons
- Open-Meteo API

## Notes
This app was built to provide a sleek, dark weather dashboard with live weather data for a selected city.
